## 鉢形城

S1で境界外と判定した原因は自治体コードでした。11362は皆野町、寄居町は11408です。J-LISの埼玉県内市町村表（皆野町113620、寄居町114081の各行。末尾は検査数字）と固定境界を照合しました。座標 `[139.193361,36.107315]` は動かさず、11408で境界内です。

- 統合マスターの史跡・成長集計エリア・公開審査を訂正済み。
- 前田利家の鉢形城候補は公開審査待ち。現行ゲーム属性の訂正が必要なため、追加専用のS1生成器へ無理に通しません。
- `site-correction-proposal.json` は同一史跡IDのmunicipalityCodeだけを変える未適用の提案。対象旧レコードのハッシュを検査してから扱います。原本ファイルを変更する実行コマンドは含みません。
- 実際の適用は別審査・ユーザー承認後。古い皆野町訪問を寄居町訪問に書き換えないでください。
- 既に獲得済みのカードはそのまま保存。修正後の新規判定は寄居町で行います。

根拠: https://www.j-lis.go.jp/spd/code-address/kantou/cms_13214181.html
固定境界と実アプリ関数の照合結果は `boundary-audit.json`。境界の版・SHA256はS1と同じです。S1の監査ファイルは当時の誤コードに対する失敗記録として保全しています。
