# WALKED v0.3.1（町田市・市区町村・都道府県フィルタ）

## 使い方
GitHub PagesなどのHTTPSサイトで index.html を公開し、iPhoneのSafariから開いてください。ページの上の3つのフィルタで「町田市」「市区町村」「都道府県」を切り替えます。

- 町田市：町丁・字境界を表示し、タップでその区域を制覇できます。境界GeoJSONを自動取得できなければ「町田市の境界GeoJSONを選択」で読み込んでください。
- 市区町村：全国の市区町村をタップして制覇できます。
- 都道府県：登録済み市区町村に対応する都道府県を緑色に表示します。この画面での手動登録はできません。
- Googleタイムライン：JSONを選択すると、保存された位置座標を境界内に照合して登録します。町田市の詳細境界データが読み込まれている場合、町田市内の地点は町丁・字単位で登録します。
- データはブラウザのlocalStorageに保存されます。バックアップ機能で定期的に保存してください。

## 注意点
町田市内の町丁・字境界はGeoshape（CODH）の2020年国勢調査ベースです。町名の正式な行政境界と一致しない場合があります。町田市内の一部は同名でも複数の調査小地域に分割されているので、同じ名前が複数表示されることがあります。

自動取得先のGeoJSON URLは接続環境により利用できない場合があります。その際は別途取得した町田市のGeoJSON（FeatureCollection）を手動で読み込んでください。自動取得・iPhone実機動作・GoogleタイムラインJSONとの整合性は未検証です。

GoogleタイムラインのGPS点と点の間は道路に沿って自動推測しません。移動中に通過した区域でも位置点がなければ未制覇のままです。GPSデータは外部サーバーへアップロードしませんが、背景地図と境界取得には通信が必要です。

## 出典
- 全国行政区域：共同通信 japan-choropleth（国土交通省 国土数値情報 2025年版、CC BY 4.0） https://github.com/kyodo-official/japan-choropleth
- 町田市町丁・字境界：CODH 国勢調査町丁・字等別境界データセット（e-Stat 2020年版、CC BY 4.0） https://geoshape.ex.nii.ac.jp/ka/resource/13209.html
- 背景地図：国土地理院 地理院タイル https://maps.gsi.go.jp/

## v0.3.1 修正
OpenStreetMap公式タイルサーバーが403で拒否したため、日本全域に対応する国土地理院の標準地図タイルに変更しました。アプリの訪問記録は従来のまま保持します。公開先の index.html を更新してブラウザを再読込してください。

### v0.3.2 地図表示範囲
「市区町村」を選択すると東京都本土全体（多摩地域・23区周辺）が地図内に収まるよう自動調整します。伊豆・小笠原諸島は離れているため初期範囲には含めません。手動で地図を移動・縮小すれば表示できます。


## v0.3.3 UI変更
- 「現在地を制覇」を「現在地を登録」に改称。
- 「全記録を削除」を通常の記録パネルから削除し、画面下部の「設定」を開いた最下部に配置。削除時の確認ダイアログは従来どおり。
- 地域検索の動作や保存形式、他の機能は変更なし。


## v0.3.4 変更点
- 町田市モードでは町丁・丁目（`m:`キー）の訪問記録だけを緑色で表示します。町田市全体（`13209`）を制覇済みでも、詳細領域には波及しません。
- 町田市境界が未読込の場合、以前の市区町村レイヤーを残さず、空の状態を表示します。
- GoogleタイムラインからGPSを取り込む際、町田市にある点は町田市全体と該当町丁の両方を記録します。詳細境界データを読み込んでからインポートしてください。
- 以前の取り込みで町丁の情報が保存されていない場合は、タイムラインJSONをもう一度取り込んでください。以前のデータを削除する必要はありません。


## v0.3.5 GoogleタイムラインJSON対応修正
- iPhoneからエクスポートしたタイムラインの配列形式（`[{ "visit": ... }, { "timelinePath": ... }]`）に対応。
- `geo:緯度,経度` 文字列から訪問地点と移動経路のGPS点を抽出。
- `durationMinutesOffsetFromStartTime` を位置情報の日時として加算。
- 他のJSON形式への対応と既存の訪問・手動登録・地図フィルタは維持。
- JSONファイルはブラウザ内で処理され、WALKEDのサーバーにはアップロードされません。
- GPS点の間の経路は推測しません。

# WALKED v0.3.7 — 町田市の町丁境界データ修正

## 原因
旧版で指定していた Geoshape のURLが間違っていました。正しい2020年版のTopoJSONは次です。
https://geoshape.ex.nii.ac.jp/ka/topojson/2020/13/r2ka13209.topojson

## GitHub Pages に適用する方法
1. このZIPを解凍。
2. GitHubの `walked` リポジトリに `index.html` をアップロードして既存ファイルを置き換える。
3. `.github/workflows/bundle-machida.yml` を同じフォルダ構造で追加する（GitHubでファイル新規作成時にファイル名を `.github/workflows/bundle-machida.yml` と入力して内容を貼り付けてもよい）。
4. GitHubの Actions で `Bundle Machida boundaries` を選択して `Run workflow` を実行する。最初のpushで自動実行されることもある。
5. Actionsの実行が緑色の成功になり、リポジトリ直下に `machida-boundaries.topojson` が追加されたことを確認する。
6. SafariでWALKEDを開き直す。町田市モードで町名・丁目の区域が表示される。
7. 境界の取得前に取り込んだタイムラインJSONは再度取り込む。すでに記録済みの市区町村データは消去不要。

GitHub ActionsからGeoshapeへの通信が失敗した場合は、ファイルは作成されません。その場合はActionsログのエラーを確認してください。

## 補足
- 地図の町丁境界はe-Stat 令和2年国勢調査のデータをGeoshape/CODHが加工したもの。195区域が掲載されています。細分割区域や複数パーツを含むため、実際に読み込むポリゴン数はファイル次第です。
- 出典: 『国勢調査町丁・字等別境界データセット』（CODH作成）「令和2年国勢調査町丁・字等別境界データ」（e-Stat）を加工 doi:10.20676/00000450 / CC BY 4.0
- WALKEDにアップロードするのは公開境界ファイルだけです。Googleタイムラインの個人データはGitHubにはアップロードしないでください。
- タイムラインの読み取り・GPS座標の市区町村照合はブラウザ内で行われます。
