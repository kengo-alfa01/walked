## 重要な確認と未解決事項

### 徳川家康：生年の暦基準

国立公文書館が紹介する『朝野旧聞裒藁』の天文11年12月26日を、国立天文台の暦日データベースで独立照合した。ユリウス暦1543-01-31、遡及グレゴリオ暦1543-02-10が対応。グレゴリオ1543-01-31を対照入力すると旧暦12月16日となる。年1543を確認値にし、和暦年対応1542を候補履歴として残した。後世の編纂資料の紹介を参照したもので、誕生日に関する全史料・陰陽道の節年説を網羅的に批判したとの意味ではない。出生地は別担当につき追加調査していない。

### 岡本良勝：記事内不整合を維持

亀山市歴史博物館の本文から1590亀山城主・改築、秀吉領の管理と検地、桑名城での自害を確認。父は正本定季に対し館は重国、峯城主は館が1572（天正2）と記す。辞典は天正2、亀山石高は館23000/辞典22000で差がある。父名・峯城主就任年・石高は新略歴から外し、誤記と断定して置換しない。生年1542?と元値1544も未確定。自害の動機・渡海の細部は追加精査待ち。

### 稲葉重通：父子・城主と城代を分離

安藤均の県博物館論文pp.1–7・9を画像化して実読。文字化けした抽出本文を読了と扱っていない。美濃だけでなく伊勢での検地、神宮造営をめぐる折衝、寄進・寺領安堵を記録。田丸城主の牧村利貞・稲葉道通と、城代としての重通を区別。論文が検討する利貞の出自の諸説、重通が清水へ戻ったという従来像、所領の全容を保留。生年不明・没年1598は寛政譜に基づく概説の範囲で確認。論文全14頁を読了したという意味ではない。

### 宇佐美定満：軍記の定行と居城説

長野市は実在定満と軍記に登場する定行を区別し、柏崎市は琵琶島城主・軍師説が後世軍記等により普及したと説明する。定行を定満の確定別名へ加えず、信繁討取り・政景を道連れにした入水・髻山籠城を定満の確定事績にしない。1489生を今回確認できず、1564没も伝聞のため未確認。居城関係自体が未確定の候補として年表に残す。柏崎の琵琶島城と信濃野尻湖の琵琶島を混同しない。

### 柿崎景家・戸田勝成

景家の1513?–1574?は公的解説にも疑問符があり確定しない。柿崎城本拠・奉行・寺社整備を要約し、軍記の勘助討取りや子晴家の最期を本人へ移さない。楞厳寺は市寺院案内の1534建立と文化財解説の再建を併記し、建立年・招聘年・再建年の対応を未確定とする。寺社整備の関係のみ抽出し、菩提寺・墓所としての重複調査はしない。

勝成の称名寺領安堵は福井県史年表の称名寺文書に基づく記載を確認。安居城主・出兵・戦死・重政/勝重は講談社辞典本文で、没年はsecondary_source_checkedとして独立確認人数に加えない。勝隆との兄弟関係や仕官順序は原史料未照合。岡本良勝にも別名重政があるが別人として保持。
