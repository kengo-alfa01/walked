### P0：村上義明と忠勝を別IDで保持

名簿2000の元出典は村上頼勝の記事で、略歴も丹羽家臣・初代藩主を指している。この範囲で初代頼勝を調査対象とした。郷土資料館監修記事は、義明と記す後世史書と、頼勝・忠勝の名が残る文書を区別する。講談社の義明項目も両人に参照するため、義明という単語だけで同定・統合しない。

主表示名「村上義明」→「村上頼勝」を判断候補として別表に残し、正本・人物名・IDは変更しない。初代の1604没は過去帳に基づく館監修記事の解説による確認で、過去帳原本の実見ではない。忠勝の1618改易・配流を初代へ移さない。

名簿1997忠勝は別の採用人物。頼勝の先の養子義忠と後の養子忠勝も分ける。出生1599は年齢から逆算確定せず、実父戸田勝隆との関係も今回未確認。館監修記事の「元和2年、大坂夏の陣」の不整合は採用せず、家中対立の発生年を略歴で断定しない。乙宝寺三重塔の寄進1614と完成1620を区別。

### P0：石川数正の没年は年換算だけでは解決しない
