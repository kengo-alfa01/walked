## 確認結果

織田信包は、津市埋蔵文化財センターの資料で長野信良からの改名、伊勢上野城から津城への移転を確認。丹波市資料で前期柏原領主としての系統、1614年大坂城内での死去を確認しました。生年1543/1548は未確認のまま併記。子信則・孫信勝、後期柏原の信休系を区別します。既存の名簿ID542の選定意図を今回の系譜だけで確定することはしません。

津市の発掘調査解説では、1580年の津城移転と五重天守は後世記録による説明で、同時代史料で確定できない旨が明記されています。遅くとも1583年11月には居城という研究上の整理を根拠に、年表は移居年不詳としました。現存天守台・小天守台は富田期とする発掘成果があり、信包の遺構と断定しません。1594年没収の後に柏原へ移ったという津市の略記と、丹波市の1598年所領付与は、同一時点とは断定せず追加照合事項に残します。お市や三姉妹の保護伝承は採用しません。

石川康勝は、松本城公式ページの1614年表欄をHTML本文で直接確認し、数正の次男で大坂冬の陣に豊臣方として参加したことを確認。研修資料は1613年の所領没収を記します。松本城主・築城主体としての兄康長や、兄の佐伯配流を康勝の事績へ転用しません。生没年、奥仁科領の詳細、別名、最期が不足するため完成略歴案は保留です。原文の値は保持します。

石田正澄は探索のみ。三成の佐和山記事を正澄の根拠として流用せず、本文確認人数と別管理しました。
