## 重要な差異・判断

### 林秀貞：追放と死亡、通称と誤称を分ける

講談社辞典は生没年を不詳とする一方、名古屋市博物館の養林寺解説は没年1580を記す。1580年の追放が確認できても死亡の独立確認にはならない。生年1513の根拠、南部勝利との同一性、追放後の活動は保留。

博物館は「通勝として広く知られる」と紹介し、辞典は秀貞が正しい名とする。通勝を確定した別名として追加・統合しない。養林寺の1562年岐阜創建は伝承として年表候補に限定し、現在の所在地・後代移転を本人の訪問先にしない。墓所・菩提寺そのものの調査は別担当。

### 塙直政：原田姓と没日の差

市の金剛寺文書紹介と辞典で塙直政・原田直政の対応と政務を確認。九郎左衛門・備中守は部分確認。重友・長俊は辞典にあるが、正勝等との時期・花押による照合は未完了。正本名・IDを維持する。

没年1576は辞典間で一致するが、講談社は旧暦5月3日、ブリタニカは5月4日。年だけ確認済みとし、没日は未解決。三津寺の戦場範囲と個人の討取者を推定しない。烏帽子形城にいたのは命令を伝える上使で、本人の在城とは読まない。

### 蜂屋頼隆・村井貞勝：政務を具体化

蜂屋は賤ヶ岳後の敦賀入部、南条郡四郎丸村の知行宛行を県史で確認。日記記載の5万石と人足割付からの4万石推計を区別し、略歴の数字には使わない。1534生の根拠、敦賀築城の着工・完成年は未確認。大谷吉継と城主の世代を分ける。

村井は京都の行政、御所修理、朝廷折衝を中心に要約。京都市の展示本文で光秀との民政と連署書状写の紹介を確認したが、電子解説の翻刻本文は取得していない。江戸期所司代の全権限を織田期に遡及させず、1582年の二条御所を現在の二条城に自動対応させない。

### 堀尾忠氏：発給文書と父子の役割

市の研究解説で、1601年知行目録、家臣への土地配分と検地、官名の信濃守から出雲守への変化、1604年没を確認。共同研究会の系譜集PDF73頁（紙面137頁）を画像でも確認し、弥助・官名・没日・享年28を照合した。ただし後世系譜の翻刻であり、同時代出生記録の判読ではない。

辞典は1577生、正本は1577/1578。1578説の原史料は未取得で、享年から一つに確定しない。松江移転の計画と、死後に父吉晴が進めた築城を区別。小山評定の逸話や辞典の「美濃川越」の地名は今回略歴に採用しない。伊勢御師への寄進から現地参拝を推定しない。

### 松平忠輝：典拠の年と史実、領地と居所を区別

上越・深谷・諏訪市資料は1592生、NDL典拠00624204の生年欄は1593。後者は1998年更新で、出典は諏訪忠輝会編『松平忠輝』。書誌的な値の差を記録したもので、1593を史実として独立確認したのではない。出典本と出生史料を確認するまで異説・要照合として保持。出生月日、改元前後の和暦表記も保留。
