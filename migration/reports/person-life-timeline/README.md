## 全国史跡調査Workへの引継ぎ手順

1. `personId`・`rosterId`で人物を対応させる。人名や別名だけで統合しない。
2. `candidateId`は本抽出の仮キー、`eventId`は根拠を追跡する記録キーとして保持する。正式な史跡ID・カードIDではない。既存人物ID台帳は変更しない。
3. 既存の史跡・史跡候補・別スレッドの場所台帳と照合する。同名の城、移転した寺、改称した城、城下町と城跡の範囲を確認する。
4. 位置・遺構範囲・現存しない場合の所在地・訪問可否を全国側で検証する。国指定・現存建築であることを採用の必須条件にはしない。
5. 年代、本人との関係、現在地、利用条件を独立判定する。参戦だけで個別陣地への到達を確定しない。禁制・寄進だけで本人の現地訪問を確定しない。
6. 採用時も元のイベントID・出典URL・確認箇所を残し、全国側の史跡IDへ対応づける。候補のままゲーム用sites/links/cardsへ直接取り込まない。

引継ぎ用ファイルはPR #2に保存します。別Workへの受領・取込確認はまだ行っていません。

## 調査の分担と確認状態

人物精査を優先し、その際に実読した資料から抽出します。出生地・墓所・菩提寺という関係はこの年表へ登録しません。清泰寺は同じ資料から得た創建・寄進だけを記録し、菩提寺調査との重複候補として明示しました。寺院の存続・墓所を改めて調査していません。

本人との関係が本文で確認できたことと、位置が確認できたことを区別しています。すべて現在地・座標は未確認、正式採用は未承認です。小倉山の築城は市が1601、大学解説が1601着工・1605完成とするため、年の意味を照合する課題を残します。原著未読の大学解説による清泰寺創建・寄進などは一部確認としています。

出典本文や画像は転載せず、事実の独自要約のみを記録。資料ごとの利用条件は未確認です。
