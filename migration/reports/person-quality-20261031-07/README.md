### 鈴木重朝（本文確認・改稿保留）

レファレンス協同DBは感状の書誌・翻刻所在を案内している。回答本文は読めたが、案内先の『徳川家康文書の研究 中巻』pp925–928を未読。質問欄の元和9没という前提を独立に確認された1623没説として加えず、正本1624も未確認のまま。

重朝の辞典リンクから誘導される孫一記事には重秀・重朝が併記され、石山合戦以降の事績が混在する。この一記事から重朝の生涯を作らない。孫三郎という宛名もまず原翻刻の照合が必要。今回のevidenceではbodyForSelectedPerson=falseとし、研究入力の確認済み側へ昇格させていない。調査記録と次の読解先はevidence・attempts・レビュー表へ保存した。
