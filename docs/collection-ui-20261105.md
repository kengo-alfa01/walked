# 日本見風録：図鑑モード切替と経歴公開状況（2026-11-05）

## 今回の変更（モード切替）

- 「地域図鑑」「戦国時代」を切り替える専用2択タブを設置。地図・訪問記録・称号・獲得カードは共通で維持
- 選択した図鑑だけを画面表示。地域図鑑モードでは戦国史跡ピンを隠し、戦国時代へ戻すと再表示
- 各モードを選ぶと内容を自動で展開。従来の二重の「開く／閉じる」ボタンは画面で非表示（互換ハンドラは保持）
- 獲得済み市区町村を地図からタップした場合は地域図鑑モードへ切り替え、該当市区町村の公開済み記事を表示
- 戦国カード獲得通知から「人物コレクションを見る」を選んだときは戦国時代モードを開く
- 初期選択は地域図鑑。選択状態は保存データに追加せず、訪問・獲得・バックアップ形式を一切変えない

## 人物紹介（長文案を保留）

ユーザー判断により「全経歴解放で約1000字の略歴」案は**今回は実装しない**。長文本文が未作成であり、本文の水増しや仮公開は行わない。

2026-11-05のPR #16で短い人物紹介まで全カード解放を条件にしていたことは誤り。今回、従来の「最初の史跡カードを獲得した段階で、公開承認済みの短文人物紹介を表示」に戻す。未獲得人物のプロフィールは非表示。

## 場所に紐づかない経歴（公開データの現状）

PR #16で、人物の最初のカードを獲得すると「場所に依存しない承認済み経歴」を年代順に表示できる処理を設けた。

ただし公開用 `sengoku/non-place-history.json` は **`entries: []` のため現時点で0件**。研究用のA本文公開判定だけではゲーム公開と見なさない。今後、人物ID・歴史ID・出典・史実根拠・利用条件・本文承認を確認したC公開データに差分投入し、適切なレコードだけ表示する。

場所依存の経歴は引き続きBの位置・安全・権利審査と公開条件に従う。位置が無いことを理由に重要な経歴を不採用にしない。未確認の位置情報や史跡を創作しない。

## 従来のPR #16の改善（継続）

1. 地図から地域図鑑を開く（制覇済みだけ）

4. 史跡ピン半径7pxから5pxへ変更
5. 場所に依存しない経歴用の承認データ読込機能（本文データは未収録）
