## 変更

- 独立した旧「📜 歴史図鑑」のパネル、開閉操作、ダイアログ、読み込み・描画処理を閉鎖。地域情報の記事入口は既存の地域図鑑へ統一。
- `history.json`の旧20件はファイルを変更せず保持。旧記事を地域図鑑へ移植しない。戦国人物・歴史カードの画面も存続。
- 「地域を探す」を「地図で地域を探す」に改名。地域名のボタンは地図移動のみを行う。
- エリア追加モードON時だけ別の「制覇／解除」ボタンを表示・許可。都道府県モードは従来通り自治体記録から集計するため編集不可。

- 町田／相模原、市区町村、全国詳細、都道府県の候補集合を維持。モード変更・詳細境界取得時に候補を再描画。候補は既存と同じ最大40件。
- 地域名ボタンをキーボードで操作可能にし、検索結果の操作ボタンに高さ44pxを確保。
- 確認用サンプルから閉鎖済み描画処理への呼び出しを除去。
